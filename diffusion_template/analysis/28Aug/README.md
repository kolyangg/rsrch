# 28 August CL39 report bundle

This directory collects the requested post-CL39 experiment index, experiment
setup documents, and the decision-relevant earlier CL39 analyses in one place.
The files are text snapshots copied on 28 August 2026; their immutable Comet
experiment keys and Serv job IDs remain inside each report.

Start with:

- `2026-08-28_post_cl39_experiment_index.md` for the cross-run lookup;
- `INIT_R_NATIVE_implementation_plan.md` for the current INIT-R-NATIVE setup;
- `CL39_branched_attention_investigation_2026-08-26.md` and
  `2026-08-26_cl39_r2_three_experiment_implementation_plan.md` for the R2
  experiment definitions;
- the dated result reports for the evidence behind the current CL39 decision.

Large generated image collections, checkpoints, rendered PDFs, and temporary
Serv snapshots are intentionally not duplicated into this Git bundle. Their
local/remote locations and content hashes are recorded in the reports.
